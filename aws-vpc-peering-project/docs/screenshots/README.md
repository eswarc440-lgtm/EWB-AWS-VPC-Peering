# Suggested project screenshots

Upload screenshots from **your own AWS Console lab**, after cropping/redacting account numbers and other identifying data:

1. VPC A and VPC B with non-overlapping CIDRs.
2. Three subnets (public A, private A, private B).
3. Internet Gateway attachment to VPC A.
4. Three route tables (show routes and subnet associations).
5. VPC peering connection in **Active** state.
6. The three security-group inbound rules (especially ICMP-only /32 sources).
7. Three EC2 instances and private-IP details; avoid exposing public IP unnecessarily.
8. App-A ↔ App-B ping connectivity evidence.
9. Security-group rule removed → 100% ping loss → restored connection, if screenshots are available.

Only upload real screenshots. Do not invent test output.
